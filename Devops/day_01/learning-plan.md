# 90-Day DevOps & Cloud Engineering Execution Plan

## 1. Context & Personal Motivation
* **Current Profile:** Working Professional 
* **Understanding of DevOps:** DevOps is not just a collection of tools, but a culture and continuous workflow that bridges software development and IT operations. It focuses on automation, reliable deployments, fast feedback loops, and infrastructure stability.
* **Why I Am Starting:** To build high-impact skills in cloud architecture, automate manual deployment toil, and position myself for a scalable career in Cloud & Infrastructure Engineering.
* **Where I Want to Reach:** A confident, job-ready DevOps mindset capable of provisioning cloud infrastructure via code, building automated CI/CD pipelines, and orchestrating containerized applications in production environments.

---

## 2. Core Objectives & Time Budget

### 90-Day Target Goals
1. Provision a fully automated, production-grade cloud infrastructure using Infrastructure as Code (Terraform).
2. Build and deploy an end-to-end zero-downtime CI/CD pipeline for a microservices app.
3. Deploy, manage, and monitor a multi-container cluster on Kubernetes with live logging and metrics.

### Core Skills to Master
* **Linux & Networking:** Shell scripting, file permissions, process management, SSH, DNS, and HTTP/HTTPS fundamentals.
* **CI/CD & Automation:** Building robust pipelines (GitHub Actions / Jenkins) with dynamic testing and security scans.
* **Containerization & IaC:** Docker container management, Kubernetes cluster operations, and Terraform state management.

### Weekly Time Commitment
* **Weekdays:** 2 hours / day (Focus: Core concepts, hands-on lab exercises, and terminal muscle memory)
* **Weekends:** 4–5 hours / day (Focus: Project builds, troubleshooting, documentation, and deep dives)
* **Total Weekly Dedicated Time:** ~18–20 Hours

---

## 3. High-Level 90-Day Roadmap

### Month 1: Fundamentals & Environment Setup (Days 1–30)
* **Linux Deep-Dive:** Bash scripting, system administration, process & memory profiling.
* **Networking & Security:** Ports, subnets, firewalls, reverse proxies (NGINX), SSL/TLS certification.
* **Version Control:** Git workflows, branching strategies, dynamic PR reviews, and GitHub best practices.

### Month 2: Automation, Cloud & Infrastructure as Code (Days 31–60)
* **Cloud Architecture:** Fundamentals of AWS/Azure/GCP (IAM, VPC/Networking, Compute, Storage).
* **Containerization:** Dockerization of multi-tier apps, multi-stage builds, and Docker Compose environments.
* **Infrastructure as Code (IaC):** Terraform basics, state management, modular configuration designs.

### Month 3: Orchestration, CI/CD & Production Readiness (Days 61–90)
* **CI/CD Systems:** Automated build, test, and release pipelines using GitHub Actions or Jenkins.
* **Kubernetes Orchestration:** Pods, Deployments, Services, Ingress controllers, Helm charts, and storage management.
* **Observability & Portfolio Project:** Monitoring with Prometheus/Grafana, centralizing logs, and publishing a production-ready Capstone project.

## 4. Consistency Strategy & Ownership
* **Daily Rule:** Minimum 1 continuous hour of practical, hands-on terminal work every single day—no exceptions.
* **Learn in Public:** Share key learnings, terminal snippets, or architectural diagrams 2–3 times a week on LinkedIn.
* **Documentation-First Mindset:** If a project isn't documented with a solid `README.md` and architecture diagram, it isn't finished.
